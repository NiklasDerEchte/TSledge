# Function: validateString()

> **validateString**(`value`, `fallback?`): `any`

Defined in: src/utils/validation.ts:25

Validates a string value, returning it if it's not empty, undefined, or null.
Returns the fallback value otherwise.

## Parameters

### value

`string`

The value to validate.

### fallback?

`any` = `null`

The value to return if validation fails.

## Returns

`any`

The validated string or the fallback.
